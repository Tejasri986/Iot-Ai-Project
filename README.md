# IoT Data Simulation + AI Dashboard

## 📌 Project Overview
This project simulates IoT sensor data (temperature & humidity), applies AI-based anomaly detection, and visualizes the results in an interactive dashboard using Streamlit. It demonstrates how IoT + AI can be combined without needing physical hardware.

## 🚀 Features
- **Data Simulation**: Generates fake IoT sensor readings (temperature & humidity).
- **Data Storage**: Saves readings into a CSV file for analysis.
- **Visualization**: Line charts showing sensor trends over time.
- **AI Anomaly Detection**: Uses Isolation Forest to detect abnormal readings.
- **Interactive Dashboard**: Built with Streamlit to display data, graphs, and anomalies.

## 🛠️ Tech Stack
- Python 3.13  
- Libraries: NumPy, Pandas, Matplotlib, Scikit-learn, Streamlit  

## 📂 Files
- `simualte.py` → Generates sensor data and saves to `iot_data.csv`.  
- `visualize.py` → Plots temperature & humidity trends.  
- `anomaly.py` → Detects anomalies using AI.  
- `app.py` → Streamlit dashboard for interactive visualization.  
- `iot_data.csv` → Sample dataset generated by simulation.  
## 📊 Example Output
- Line chart of temperature & humidity over time.  
- Scatter plot highlighting anomalies in red.  
- Dashboard showing sensor data and anomaly count.  

## 🎯 Use Cases
